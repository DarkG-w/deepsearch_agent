# Deepsearch Agent:多智能体深度搜索系统

基于DeepAgents构建面向复杂研究任务的多智能体深度搜索系统，设计Planner +三类执行Agent的任务流程，实现知识库检索、数据库查询、网页补充搜索和报告生成的一体化问答。

## 功能特性

Harness多智能体架构：基于FastAPI+DeepAgents设计Harness Agent执行框架，封装请求接入、Thread ID 会话隔离、工作目录创建、上下文注入、工具注册和WebSocket进度推送能力；主智能体负责任务规划与结果汇总，子智能体分别对接Tavily、MySQL、RAGFlow，实现互联网、业务数据库和私有知识库的多源检索融合。
可插拔Skill：设计Agent技能扩展机制，将资料分析、代码审查、报告生成等固定流程沉淀为可复用Skill，并封装搜索、SQL查询、RAGFlow问答、Markdown生成、PDF转换等工具，实现复杂问题从输入到研究报告输出的自动化流程，将单次报告生成时间缩短至1～3分钟。
完整评测体系：引入搜索质量评估器、缓存机制和Trace任务回放能力，对多源检索结果进行可信度评分，缓存高频查询结果，并按Thread ID记录完整执行链路；测试集中报告有效信息命中率由约76%提升至89%，重复调用减少约40%，平均响应耗时降低约33%，异常定位时间缩短至5分钟以内。
